# AZIZ Knowledge Studio — مشروع Android

هذا المشروع يحوّل ملف HTML المرفق إلى تطبيق Android بسيط باستخدام WebView، مع إبقاء HTML وJavaScript كما هما داخل التطبيق.

## بناء APK عبر GitHub (بدون تثبيت Android Studio)

1. أنشئ مستودعًا جديدًا على GitHub وارفع جميع ملفات هذا المجلد إليه.
2. افتح تبويب **Actions** في المستودع.
3. اختر **Build AZIZ APK** ثم اضغط **Run workflow**.
4. بعد انتهاء البناء بنجاح، افتح نتيجة التشغيل وانزل إلى **Artifacts**.
5. نزّل `AZIZ-Knowledge-Studio-debug-apk.zip` وافتحه؛ ستجد `app-debug.apk`.
6. انقل APK إلى هاتف Android وثبّته. قد يطلب الهاتف السماح بالتثبيت من هذا المصدر.

## ملاحظات مهمة

- هذه نسخة Debug للتجربة والتثبيت الشخصي، وليست نسخة متجر Google Play موقّعة بمفتاح إصدار.
- الكتالوج والسلة ورمز المالك محفوظة محليًا على الجهاز عبر LocalStorage؛ لا تتم مزامنتها تلقائيًا بين الأجهزة.
- الخطوط قد تحتاج اتصال إنترنت لأنها تُحمّل من Google Fonts.
- تأكد من تغيير رقم واتساب داخل ملف `index.html` إذا أردت رقمًا مختلفًا.
